## Sobre o projeto

Site e cardápio digital da Luz Gastronomia. O visitante pode explorar pratos, filtrar categorias, montar combos e organizar itens na sacola.

## Destaques

- Cardápio com busca e filtros por categoria
- Montagem de combos personalizados
- Sacola de pedidos e informações de compra
- Layout responsivo para celular e computador

## Estrutura do repositório

- `Sistema Luz Gastronomia/` — arquivos da aplicação.
- `luz-gastronomia-netlify/` — versão com configuração específica para Netlify.
